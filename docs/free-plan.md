# План «бесплатно»: что делать, чтобы ни за что не платить

Самодостаточный план расходов сайта. Факты о лицензии, Winter CMS и плагинах —
`docs/plugins.md`; здесь только решения «что делать» и чем это проверяется.
Данные на 11.11.2026, внешние тарифы меняются — перед покупкой/разворотом
проверять на дату.

**Итог одной строкой:** плагины — ноль платных, сервер, SSL, CDN, почта,
мониторинг и CI — на бесплатных тарифах; платной остаётся **только домен**.

## 1. Лицензия October: $0 первый год, $39/год — по желанию

| Что | Бесплатно? |
|---|---|
| «One Free License» на один проект, включая коммерческий | **да, $0**, год обновлений включён (`octobercms.com/pricing`) |
| Продление обновлений после года | **нет**, $39/год |
| Работа сайта после окончания лицензии | **да**, навсегда, на скачанной версии |
| Обновления и `composer update` после года | **по лицензии нет** (EULA §3: Updates — только в Active Term) |
| Правка ядра `modules/` и `vendor/` | **запрещена** (EULA §7.4) |
| Поддержка вендора | **не входит** и в платную лицензию (EULA §8) |

Источник цифр — `octobercms.com/pricing` (11.11.2026); условия — локальный
`LICENSE.md` (EULA, 26 767 байт, §3, §4, §7.4, §8).

Что делать:

1. **Оформить бесплатную лицензию** на проект. Она стоит $0, но выдаётся через
   аккаунт (EULA §4). Сейчас сайт поднят без ключа — для прода это единственная
   лицензионная дыра. Решение за владельцем: `Что доделать.txt`, M3.
2. **Не продлевать обновления.** Зафиксировать 4.4.13 и хранить архив
   установки: `vendor/`, `composer.lock`, дамп БД. Gateway после окончания
   лицензии не отдаёт файлы даже старых версий.
3. **Не обновлять в обход Gateway** — это нарушение EULA, а не экономия.
4. **Компенсировать отсутствие security-обновлений:** ноль сторонних плагинов,
   Cloudflare перед сайтом, бэкап по cron, вход в админку только для своих,
   минимальная поверхность (один плагин `nlb/library`).
5. **Пересматривать решение раз в год.** $39 — цена часа подрядчика; если за
   год не появилось ни одной security-правки в 4.4, продление можно отложить.

## 2. Плагины: ни одного платного, ни одного обязательного

| Задача | Платный вариант | Бесплатно |
|---|---|---|
| SEO-поля записей, JSON-LD | Renatio.SeoManager ($20) | свои поля в blueprints + `seo` partial (M20) |
| sitemap.xml, robots.txt, 301 | — | контроллер + таблица редиректов (M20) |
| Отзывы | — | своя `nlb_reviews` (M21) |
| Формы и письма | Martin.Forms и др. | Laravel-маршруты + `Mail::queue` (этап 5) |
| PDF брони | — | `@media print` в CSS или `barryvdh/laravel-dompdf` (MIT) |
| Поиск | поисковые SaaS | MySQL `FULLTEXT` (P1-20) |
| Push-уведомления | платные сервисы | Web Push + VAPID (M9), FCM для Android |
| Загрузка фото | Responsiv.Uploader (бесплатный) | своя валидация в форме + `storage` |
| Бэкапы | платные агенты | `mysqldump` + `tar` в cron, копия через `rclone` |
| Антиспам | платная captcha | honeypot + rate limit + Cloudflare Turnstile (free) |

Правило: сторонний плагин ставится только если без него нельзя, и тогда — из
бесплатного списка `docs/plugins.md` (не больше трёх на проект). Платных
плагинов в проекте быть не должно: их нет ни в одном пункте бэклога.

## 3. Хостинг и обвязка

| Что | Бесплатный вариант | Ограничение |
|---|---|---|
| Сервер | Oracle Cloud Always Free (ARM Ampere, до 4 OCPU / 24 ГБ) | аккаунт с картой, лимиты меняются, инстанс должен быть живым |
| Альтернатива | Fly.io free allowance (Docker) | free-tier засыпает, публичный домен ограничен |
| DNS, CDN, SSL, WAF | Cloudflare Free + Let's Encrypt | нет SLA, часть стран под замедлением |
| Git и CI | GitHub Actions (публичный репозиторий — без лимита минут) | приватный — 2 000 минут/мес |
| Мониторинг | UptimeRobot Free + Sentry Free + Cloudflare Analytics | 5-минутный интервал, 5 000 ошибок/мес |
| SMTP | Яндекс 360 на домене или Brevo Free (300 писем/день) | лимиты и антиспам-политика меняются (M14) |
| Cron | cron хостинга или cron-job.org | внешний cron не запускает `artisan` с локальным путём |
| Облачная копия бэкапа | `rclone` в бесплатное облако (5–15 ГБ) | квота |

Бесплатные shared-хостинги (InfinityFree и подобные) **не годятся**: нет SSH и
cron, лимит писем, формы и брони туда не ставить.

## 4. Что бесплатно не будет

- **Домен** — единственная неизбежная плата: `*.vercel.app`/`*.fly.dev` для
  библиотеки не подходят, а PHP-хостинг без домена бессмысленен.
- **SMS** и платные API (OpenAI и подобные) — только если появятся такие фичи.
- **Эквайринг** — комиссия с оборота, если появятся платные услуги.
- **Поддержка вендора** — её нет и в платной лицензии.

## 6. Чек-лист перед запуском (бесплатный контур)

- [ ] Бесплатная лицензия оформлена **или** есть письменное решение работать
      без ключа (M3).
- [ ] Архив установки (`vendor/`, `composer.lock`, дамп БД, `storage/app`) снят
      и проверен восстановлением один раз.
- [ ] В `plugins/` нет ни одного платного плагина; сторонних — не больше трёх.
- [ ] `composer audit` чистый, секретов в репозитории нет.
- [ ] SMTP бесплатный, живое письмо прошло по всем четырём сценариям (M14).
- [ ] Бэкап по cron, копия вне сервера, восстановление проверено.
- [ ] UptimeRobot и Sentry отвечают, алерт приходит на почту.
- [ ] Домен оплачен и продлён (единственная статья расходов).
- [ ] Cloudflare включён, SSL — Let's Encrypt, HSTS/заголовки на месте (P1-4).

## 7. Чем этот план рискует

- **Free-tier — не SLA.** Oracle, Cloudflare, Brevo, UptimeRobot могут изменить
  лимиты или потребовать карту; держать план Б (локальный стенд + бэкап).
- **Нет security-обновлений** после первого года: растёт цена инцидента, поэтому
  ноль сторонних плагинов и бэкап — не «приятная мелочь», а часть плана.
- **Бесплатная почта режет рассылки** агрессивнее платной: письма форм — да,
  массовые рассылки — нет.
- **Cloudflare Free** не спасает от таргетированной нагрузки; при атаке нужен
  платный тариф либо блокировка на уровне хостера.
- **Домен** дорожает при продлении; регистратор выбирается один раз.
