## 2. Гигиена документации

- Новые правила не добавляются в `.txt`. `.txt` — только журнал и бэклог.
- Если файл не упомянут в `AGENTS.md`, `README.md` или здесь — он архив.
- Каждый пункт бэклога содержит `file:line` источника либо точный путь в админке October.
  Пункт без доказательства не принимается.
- Закрытый пункт удаляется из `Что доделать.txt` целиком и попадает одной записью
  в `Что сделано.txt`.
- Числа (размеры, количество файлов, версии) берутся из кода/каталога и перепроверяются
  командой, а не перепечатываются из старых отчётов.
- Пока сайт не установлен, «проверено» означает «проверено по источнику и его гейтам».
  После этапа 1 к этому добавляется PHPUnit на реальной БД (`vendor/phpunit/phpunit/phpunit`).
- Документы источника (`D:\nlbbootstrap-main\docs\*`) остаются его документами.
  Ссылаться на них можно, копировать сюда — нет: копия протухнет молча.
