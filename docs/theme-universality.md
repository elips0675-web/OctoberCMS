# Конструктор страниц: как собрать страницу в админке

Документ для контент-менеджера и для того, кто будет дорабатывать блоки.
Код: `plugins/elv/library/classes/PageBuilder.php`, blueprint
`plugins/elv/library/blueprints/page/structure.yaml` и
`plugins/elv/library/blueprints/blocks/builder.yaml`, шаблон
`themes/elv/pages/builder.htm`, партиалы `themes/elv/partials/blocks/*.htm`.

## 1. Что это и чего это не касается

Страница конструктора — запись Tailor (`Elv\Page`), состоящая из блоков.
Адрес — один сегмент: `/adres-stranicy/`.

**110 существующих адресов на конструктор не переводятся.** Их разметка и
текст сверяются с эталоном `preview/` гейтом `tools/check-dom-parity.mjs`
(110 HTML, `tools/check-dom-parity.mjs:108-111`). Конструктор — только для
новых страниц; перевод существующей — отдельное решение владельца с осознанной
потерей 1:1.

## 2. Создание страницы

Админка → «Tailor» → «Страницы» (`primaryNavigation` в blueprint) → «Создать».

| Поле | Что значит |
|---|---|
| Заголовок | `<h1>` страницы и `title` вкладки, если не заполнено поле ниже |
| Адрес (slug) | сегмент адреса: `pravila-proezda` → `/pravila-proezda/` |
| Включено | снятая галочка = 404 и отсутствие в `/sitemap.xml` |
| Краткое описание | подзаголовок под `<h1>` и описание для поиска, если пусто поле ниже |
| Заголовок для поиска | `seo_title`, до 60 символов |
| Описание для поиска | `seo_description`, до 160 символов |
| Блоки страницы | повторитель блоков: порядок строк = порядок на странице |

Адрес страницы неизменен после публикации: ссылки в карте сайта и внешние
ссылки ведут на него. Менять slug — только вместе с 301. Вложенных адресов
нет (`structure.maxDepth: 1` в blueprint): конструктор даёт один сегмент, иначе
`fullslug` перестал бы совпадать с адресом.

## 3. Блоки

Порядок блоков на странице произвольный; каждый блок — отдельный партиал
`themes/elv/partials/blocks/<группа>.htm`. Неизвестная группа пропускается
молча (`PageBuilder::GROUPS`), поэтому страница не падает от старой строки
повторителя.

| Блок | Поля | Что делает |
|---|---|---|
| Текст | подзаголовок, текст (richeditor) | абзацы; подзаголовок становится `<h2>` с якорем |
| Текст с картинкой | подзаголовок, текст, картинка, положение картинки, подпись | две колонки: текст и изображение слева или справа |
| Цитата | вид (цитата / примечание / предупреждение), текст, автор | `<blockquote>` или выделенный блок-примечание |
| Сетка записей | подзаголовок, раздел, сколько записей (1…12) | карточки раздела + ссылка «Смотреть все» |
| Видео | подзаголовок, файл, обложка, подпись | `<video>` со своего домена; внешние плееры не подключаются |
| Оглавление | заголовок блока, показывать третий уровень | список ссылок на подзаголовки страницы |

Правила, которые действуют на все блоки:

- **Один запрос к БД на блок.** Блок «сетка» берёт записи через
  `Content::records()` — тем же запросом, что и разделы, с тем же фильтром
  опубликованности. Второй источник выборки не заводится.
- **Картинки — из темы.** `elv_picture()` (плагин, `classes/Media.php:89`)
  подставляет `/themes/elv/<путь>`, поэтому в поле картинки указывается путь
  внутри темы, например `assets/images/news-1.jpg`. Медиатека October для
  картинок не используется: файл из неё получил бы другой адрес и другую
  оптимизацию.
- **Видео — файл, не iframe.** Внешние плееры отсекает CSP
  (`default-src 'self'`): вставленный YouTube всё равно не отрисуется, поэтому
  `PageBuilder::fileUrl()` отбрасывает адреса с чужих доменов. Свой файл
  кладётся в медиатеку October, обложка — в тему.
- **Никакого JavaScript.** Оглавление собирается на PHP
  (`PageBuilder::bodyAnchors()`), id расставляет сервер, поэтому ссылки
  работают и без скриптов, и в печати.

## 4. Оглавление и якоря

Оглавление собирается из двух источников: подзаголовок каждого текстового
блока и `<h2>/<h3>` внутри richeditor. Якорь — транслит заголовка
(`Str::slug`): «Правила проезда» → `pravila-proezda`. Одинаковые заголовки
нумеруются: `pravila-proezda`, `pravila-proezda-2`.

Блок «Оглавление» ставится первым, если он нужен: он печатает ссылки на
заголовки, которые идут **ниже** в разметке. При `include_h3 = false`
показываются только `<h2>`.

## 5. Ошибки и края

| Ситуация | Поведение |
|---|---|
| Неизвестный адрес | 404 со страницей «Страница не найдена» (`pages/builder.htm`, `setStatusCode(404)`) |
| Страница выключена | 404, в карте сайта её нет (`PageBuilder::find()` → `applyVisibleFrontend()`) |
| Блок с неизвестной группой | строка пропускается, остальные блоки рендерятся |
| Раздел вне белого списка | блок «сетка» пуст (не «все записи сайта») |
| `limit` больше 12 | обрезается до 12 (`PageBuilder::MAX_LIMIT`) |
| Внешний адрес видео | отбрасывается, плеер не выводится |

## 6. Что проверяет приёмка

- `plugins/elv/library/tests/PageBuilderTest.php` (12 тестов): рендер блока,
  404 на неизвестный адрес и на выключенную страницу, якоря и дубли, фильтр
  третьего уровня, неизвестная группа, сетка записей и лимит, запрет внешнего
  видео, **совпадение групп blueprint с партиалами** и **разделов сетки с
  белым списком**, **наличие правил CSS для каждого класса блоков**.
- `plugins/elv/library/tests/SeoTest.php`: страница попадает в
  `/sitemap.xml`, выключенная — нет; перечень статических страниц карты
  по-прежнему сверяется с `themes/elv/pages/*.htm`, причём страницы с
  параметром в адресе (`url = "/:slug"`) из сверки исключены.
- Живые гейты после сборки: `check-urls` (109 адресов 200, `/non-existent/` —
  404 со страницей), `check-dom-parity` (110/110), `check-seo`,
  `check-headers`, `check-orphans`, `purge-css --check`,
  `check-css-budget`.

## 7. Как добавить новый блок

1. Группа в `plugins/elv/library/blueprints/blocks/builder.yaml` (`groups:`) —
   ключ группы совпадает с именем партиала.
2. Партиал `themes/elv/partials/blocks/<группа>.htm`; данные приходят в
   `block.data`, поля перечислены в `PageBuilder::FIELDS`.
3. Если блоку нужна подготовка (записи, якоря, адрес файла) — в
   `PageBuilder::prepare()`; шаблон не должен обращаться к моделям.
4. Классы — только существующие (`bootstrap.min.css` после `purge-css` или
   `styles.css`): тест `testBlockClassesExistInStylesheets` падает на классе
   без правил, а `purge-css --check` — на расхождении сборки CSS с разметкой.
   Класс, собранный в PHP из данных, добавляется в `safelist`
   `tools/purge-css.mjs` — иначе он выпадет из сборки.
5. Классы внутри `class="..."` не должны содержать кавычек и должны быть
   отделены пробелами от `{% ... %}`: `purge-css` читает разметку регулярным
   выражением, и склеенный токен (`%}order-lg-2`) или вложенная кавычка
   (`alert alert-{{ kind == 'warning' … }}`) выкидывают класс из выборки.
6. Прогнать `phpunit -c phpunit.elv.xml` и `node tools/purge-css.mjs`, затем
   `--check`.

## 8. Границы этапа

Каркас закрыт: страница, шесть блоков, 404/SEO/карта сайта, тесты. Вторым
шагом (отдельные пункты бэклога) — баннеры (`Elv\Banner` с позициями показа) и
пресеты карточек. Перевод существующих 110 адресов, конструктор шапки и
подвала, тёмная тема и «Читайте также» — отклонены или отложены решением
владельца (`docs/roadmap.md` §4, §8).
