# Плагины, лицензия и расширение сайта

Канон по трём вопросам: сколько стоит October и что с Winter CMS, какие плагины
ставим и какие нет, чего не хватает до «универсального сайта» с блогом и отзывами.
Числа проверены 11.11.2026 на живом сайте и в карточках Marketplace (фильтр 4.x).

## 1. Лицензия October CMS

| Что | Значение |
|---|---|
| Первая лицензия | бесплатно, включая коммерческие проекты |
| Обновления | 1 год включён, продление **$39/год** за сайт |
| Unlimited | $26/мес, **$312/год**, без ограничения числа сайтов |
| Срок жизни скачанной версии | **вечный**: оплата покупает обновления, а не право работы |
| Update Gateway | требует **активную** лицензию, даже для старых версий |

Источник: `octobercms.com/pricing` (11.11.2026). Актуальный релиз — 4.4.14
(10.11.2026), у нас 4.4.13.

Решения:

1. Работаем на self-host, **ничего не покупаем без письменного решения владельца**
   (`project-context.md`, раздел 3).
2. Перед релизом — сохранить архив установки (`vendor/`, `composer.lock`,
   дамп БД): без активной лицензии файлы заново не скачать.
3. $39/год — стоимость обновлений, а не «сайт перестанет работать». Продление
   обязательно только ради security-фиксов; откладывать его дольше года нельзя.

## 2. Winter CMS: не берём

| | October CMS 4.4 | Winter CMS 1.2 |
|---|---|---|
| Лицензия | $39/год за обновления | MIT, бесплатно |
| Версия | 4.4.14 | 1.2.15 |
| Фреймворк | Laravel 12 | **Laravel 9** (`"laravel/framework": "^9.1"` в `composer.json`) |
| PHP | 8.2–8.4 | 8.1+ |
| Tailor | `entry`, `stream`, `structure`, `submission` | **нет** |
| Плагины 4.x | совместимы | только совместимые с October **1.x** |

Причины отказа, по убыванию веса:

1. **Tailor — основа проекта.** Девять blueprints (6 сущностей + 3 раздела),
   `type: structure` для вложенных разделов, `tailor:migrate`, `nlb:import`.
   В Winter Tailor отсутствует: каждый blueprint — миграция + модель + контроллер
   + админ-форма. Это переписывание data-слоя, а не «пять строк в composer».
2. **Laravel 9 не получает security-фиксов** с 06.02.2024
   (`laravel.com/docs/9.x/releases`, таблица поддержки). В `composer.json` Winter
   это признано открыто:
   ```json
   "policy": { "advisories": { "ignore": { "laravel/framework": {
       "on-audit": false, "reason": "Winter CMS 1.2 requires Laravel 9" } } } }
   ```
   Для сайта с формами, бронями и почтой это прямой риск, а не теория.
3. **Экономия нулевая:** первый год October бесплатный, дальше $39/год. Переезд
   дороже на порядок.

Winter оправдан, только если сайт форкается и продаётся без вендора или
разворачивается на старом PHP 8.1 без обновлений. Для библиотеки с бронями — нет.

## 3. Минимальный набор плагинов: не больше трёх

Правило: **один плагин = одна задача**, ставится по необходимости, а не «на всякий
случай». Каждый плагин добавляет миграции, обновления и контекст для ИИ-агента.

| Задача | Плагин | Факты (11.11.2026) | Когда ставим |
|---|---|---|---|
| 301 с URL Битрикса | **Vdlp.Redirect** | бесплатно, 23 262 установки, 4.x | при переезде домена/структуры; без него теряются позиции |
| SEO-поля записей, JSON-LD, sitemap | **Renatio.SeoManager** ($20, 807 проектов) или **Initbiz.SeoStorm** (бесплатно, 2 824) | 4.x | если полей в blueprints не хватит; сначала пробуем свои |
| PDF (бронь, чек) | **Renatio.DynamicPDF** | бесплатно, 28 751, v9.0.1, PHP 8.2+, October 4.4+, тянет `barryvdh/laravel-dompdf` | когда библиотека захочет PDF-подтверждение |
| Медиа в S3 | **October.Drivers** | официальный, бесплатный | только после переезда на S3 |
| Загрузка фото с фронта | **Responsiv.Uploader** | 2.0.1, 13 452, 4.x, обновлён 03.2026 | только для отзывов с фото |

Перед установкой любого плагина проверить: строка «Platform Compatibility»
содержит 4.x; дата последнего обновления не старше года; требуемая версия PHP
не выше 8.3; `composer audit` после установки чистый; миграции не трогают наши
таблицы `nlb_*` и `tailor_*`.

## 5. Разбор черновика «Архитектура October CMS: Маркетплейс + Бронирование»

Черновик владельца (`Архитектура … deepseek.html`) в git не попадает, но его
выводы проверены по коду — чтобы не повторять ошибки.

**Верно:**

- `app/blueprints/` для глобальных сущностей поддерживается:
  `modules/tailor/classes/BlueprintIndexer.php:215` проверяет `app_path('blueprints')`.
- `type: submission` существует: `modules/tailor/classes/Blueprint.php:533`,
  `SubmissionBlueprint`, `SubmissionComponent`, письмо `tailor:submission`,
  модерация и honeypot.
- `type: structure` существует (`Blueprint.php:530`) и уже используется:
  `plugins/nlb/library/blueprints/*/section.yaml` (`Nlb\NewsSection`,
  `Nlb\BookSection`, `Nlb\EventSection`).
- Блог на Tailor для контентных новостей достаточен — у нас уже так.
- `{% cache %}` для анонимных тяжёлых блоков — верно.

**Требует правки:**

- «Honeypot встроен в October» — **нет**, только в Tailor-компоненте
  `SubmissionComponent` (`:178`, `:263`), не в CMS вообще.
- «`submission` сэкономит дни» — только если устраивает его разметка. У нас
  правило «1:1 с `preview/`», поэтому форму рисуем свою, а `submission` создаёт
  **второй** склад отзывов (`tailor_*`) рядом с `nlb_*`. Для отзыва после брони
  честнее своя таблица (M21).
- «POWER SEO Toolkit / SeoCore» — см. раздел 4: один и 63 установки
  соответственно; безопаснее Renatio.SeoManager или свои поля.
- «Shopaholic — ставите только нужные модули» — у Lovata это связка плагинов,
  а не один модуль.
- «DynamicPDF без тяжёлых зависимостей» — тянет `barryvdh/laravel-dompdf`;
  для кириллицы нужен DejaVu Sans.
- «Tailor в 10× быстрее RainLab.Blog» — непроверяемое маркетинговое число;
  для блога с комментариями и RSS RainLab богаче из коробки.

**Чего в черновике нет:** `/sitemap.xml`, `/robots.txt`, 301-карта, политика
модерации отзывов, 152-ФЗ и согласие на обработку, бэкапы, очередь и cron,
staging, тесты новых фич, стоимость лицензии и цена перехода на Winter.

## 6. Чего не хватает до универсального сайта

| Домен | Состояние 11.11.2026 | Пункт бэклога |
|---|---|---|
| **Блог** | есть `Nlb\News` (`news/item.yaml`, `type: stream`) с автором, тегами, обложкой, `read_time`, `source_url` и разделами (`section.yaml`, `type: structure`); нет RSS и мета записи (`seo_title`/`seo_description` у записи) | P2-6 (RSS), мета — в M20 |

| **SEO** | canonical, OG, robots — в `themes/nlb/layouts/default.htm:14-27`; JSON-LD в теме нет (0 совпадений `ld+json`); `/sitemap.xml`, `/robots.txt`, `/rss.xml` — **404** (проверено) | M20 (sitemap, robots, 301, мета записи, базовый JSON-LD), P2-4 (Event/Product), P2-6 (RSS) |
| **Формы** | разметка и клиентская валидация 1:1, согласие на обработку есть в `feedback.htm:51` и `services-detail.htm:184`; серверных `POST` нет | P0-4, P0-5, P1-9, P1-12 (этап 5) |
| **Почта** | `MAIL_MAILER=log`, живого SMTP нет | M14 |
| **Инфраструктура** | нет staging, хостинга, бэкапов и мониторинга; `QUEUE_CONNECTION=database`, но воркера и cron нет | M17, P2-2 (CI) |
| **Контент** | 59 из 91 позиции без фото; контакты и реквизиты — заглушки; права на демо-фото не зафиксированы | P1-11, P0-6, P0-7 |

Порядок работ: сначала этап 5 (формы и письма), затем M20 (SEO-периметр),
затем M21 (отзывы); поля блога уже есть, лента — P2-6. Плагины — только когда
без них нельзя.

## 7. Бесплатный контур: как не заплатить ни за что

### 7.1 Лицензия

| Что | Бесплатно? |
|---|---|
| Одна лицензия на проект (первый год) | **да, $0**, включая коммерческие проекты (`octobercms.com/pricing`) |
| Продление обновлений после года | **нет**, $39/год |
| Работа сайта после окончания лицензии | **да**, навсегда — на скачанной версии |
| Обновления и `composer update` после года | **по лицензии нет** (EULA §3: Updates — только в Active Term) |
| Правка ядра `modules/` и `vendor/` | **запрещена** (EULA §7.4) — все доработки в `plugins/nlb/library` и `themes/nlb` |

Что делать, чтобы не платить:

1. Оформить **бесплатную** лицензию на проект (она стоит $0, но выдаётся через
   аккаунт — EULA §4; решение за владельцем, сейчас установка идёт без ключа:
   M3). Это единственный легальный «бесплатный» путь для прод-сайта.
2. Не продлевать обновления: зафиксировать 4.4.13, хранить архив установки
   (`vendor/`, `composer.lock`, дамп БД) — Gateway после истечения лицензии
   файлы не отдаёт, даже старые версии.
3. Не обновлять в обход Gateway: это нарушение EULA, а не экономия.
4. Компенсировать отсутствие security-обновлений: ноль сторонних плагинов,
   Cloudflare (WAF, кеш), бэкапы по cron, вход в админку только для своих,
   минимальная поверхность (только `nlb/library`).
5. Пересматривать решение раз в год: $39 — это цена одного часа работ
   подрядчика, продление дешевле, чем один инцидент.

### 7.2 Плагины: ноль платных, ноль обязательных

| Задача | Платный вариант | Бесплатно |
|---|---|---|
| SEO-поля записей, JSON-LD | Renatio.SeoManager ($20) | свои поля в blueprints + `seo` partial (M20) |
| sitemap.xml, robots.txt, 301 | — (платных и нет) | контроллер + таблица редиректов (M20) |
| Отзывы | — | своя `nlb_reviews` (M21) |
| Формы и письма | Martin.Forms и др. | Laravel-маршруты + `Mail::queue` (этап 5) |
| PDF брони | Renatio.DynamicPDF (сам бесплатный, но тянет dompdf) | `@media print` в CSS или `barryvdh/laravel-dompdf` (MIT) |
| Поиск | поисковые SaaS | MySQL `FULLTEXT` (P1-20) |
| Push-уведомления | платные сервисы | Web Push + VAPID (M9), FCM для Android — бесплатно |
| Загрузка фото | Responsiv.Uploader (бесплатный) | своя валидация в форме + `storage` |
| Бэкапы | платные агенты | `mysqldump` + `tar` в cron, копия через `rclone` |
| Антиспам | платная captcha | honeypot + rate limit + Cloudflare Turnstile (free) |

Итог: из платного списка не нужен **ни один**. Единственный реально полезный
бесплатный сторонний плагин — `Vdlp.Redirect` (301), но и он заменяется
20 строками своего кода, если не хочется третьей зависимости.

### 7.3 Хостинг и обвязка

| Что | Бесплатный вариант | Ограничение |
|---|---|---|
| Сервер | Oracle Cloud Always Free (ARM Ampere, до 4 OCPU / 24 ГБ) | лимиты меняются, аккаунт с картой; сайт должен быть живым |
| Альтернатива серверу | Fly.io free allowance (Docker), локальный стенд | free-tier засыпает / на нём нет публичного домена |
| DNS, CDN, SSL, WAF | Cloudflare Free + Let's Encrypt | нет SLA, часть стран под замедлением |
| Git и CI | GitHub Actions (публичный репозиторий — без лимита) | приватный — 2 000 минут/мес |
| Мониторинг | UptimeRobot Free + Sentry Free + Cloudflare Analytics | 5-минутный интервал, 5 000 ошибок/мес |
| SMTP | Яндекс 360 (домен) или Brevo Free (300 писем/день) | лимиты и антиспам-политика меняются (M14) |
| Cron | cron хостинга или cron-job.org | внешний cron не умеет artisan-команды с локальным путём |
| Облачная копия бэкапа | `rclone` в бесплатное облако (5–15 ГБ) | квота |

Тарифы внешних сервисов меняются — перед решением проверять на дату (это не
наши данные, в отличие от `file:line` в коде).

### 7.4 Что бесплатно не будет

- **Домен** — единственная неизбежная плата: `*.vercel.app`/`*.fly.dev` не
  подходят для библиотеки, а PHP-хостинг без домена бессмысленен.
- **SMS** и платные API (OpenAI и подобные) — только если появятся такие фичи.
- **Эквайринг** — комиссия с оборота, если появятся платные услуги.
- **Поддержка вендора** — её нет и в платной лицензии (EULA §8).

### 7.5 Порядок «сначала бесплатно»

1. Этап 5 — формы и письма (бесплатный SMTP на время разработки — `log`).
2. M20 — SEO-периметр своим кодом, без плагинов.
3. M21 — отзывы своей таблицей.
4. M17 — Oracle Always Free + Cloudflare + Let's Encrypt; бэкап по cron.
5. M14 — бесплатный ящик на домене, живое письмо на каждый сценарий.
6. M9/P2-6 — Web Push и RSS, тоже без плагинов.
7. Через год — решить по $39: продлевать или замораживать версию.
