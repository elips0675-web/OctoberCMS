# Архив документации

Здесь лежит то, что **перестало быть правдой**, но нужно для истории. Правило
простое: если документ противоречит коду или `docs/README.md` — он переезжает
сюда с датой среза и ссылкой на канон, а не правится «чтобы было похоже».

## Что сюда попадает

- отчёты о замерах, которые устарели после смены версии October или CSS;
- черновики планов, заменённые `Что доделать.txt`;
- документы источника `D:\nlbbootstrap-main\docs\*`, если понадобится
  процитировать состояние Битрикса на дату переезда (копировать их целиком не
  нужно — они остаются в источнике).

## Что сюда не попадает

- действующие правила — они только в `AGENTS.md` и `docs/*.md`;
- открытые пункты — только в `Что доделать.txt`;
- секреты, дампы, персональные данные — ни в каком виде.

## Формат записи

Каждый файл архива начинается с шапки:

```
> Дата среза: ДД.ММ.ГГГГ
> Заменено: <файл в docs/>
> Почему: <одна строка>
```

устаревал.
