## 4. Отклонено

- **Fortify, CSP-плагин, Meilisearch, RainLab.Revisionable, Spatie Backup как
  плагины.** Правило «один плагин `nlb/library`» (`AGENTS.md`, правило 5,
  `docs/plugins.md`) не отменяется: то же делается кодом плагина или
  штатными таблицами. Исключение — только из списка `docs/plugins.md`.
- **Замена `Content::flush()` на тегированный кэш сейчас.** Кэш запроса не
  переживает запрос; теги появятся вместе с полностраничным кэшем, иначе это
  кэш ради кэша.
- **«Универсальные пути» вместо `D:\nlbbootstrap-main` в документации.**
  Источник миграции — часть условия задачи (`AGENTS.md`, §1), его путь должен
  быть точным. Машинные пути PHP/Composer остаются в `README.md` и
  `docs/installation.md` как инструкция для этой машины.
- **Snapshot-файл `.ai/context-snapshot.md` и `docs/ai-examples/`.** Их роль
  уже выполняют `Что сделано.txt` (что и чем проверено) и код проекта;
  третий журнал протухнет молча.

| Тезис оценки | Решение и проверка |

## 7. Как этим пользоваться

1. Перед новой работой — сверить пункт с этим документом: если он здесь
   «отклонено», второй раз не обсуждать.
2. Закрытый пункт бэклога удаляется из `Что доделать.txt` и попадает записью
   в `Что сделано.txt`; строку в таблице §2–3 тогда править не нужно —
   она ссылается на номер пункта, а номер исчезает вместе с пунктом.
3. Оценка не является источником факта: числа (тесты, адреса, размеры)
   берутся из прогона, а не из HTML.

## 8. WPShop: что применимо к этому сайту

Второй черновик владельца (12.11.2026, 16 идей) предлагает «универсальность»
из WordPress-шаблона WPShop: конструктор страниц, TOC, баннеры, «Читайте
также», пресеты карточек, шорткоды, лайтбокс, конструктор шапки и подвала.
Общий тезис верный — брать UX и удобство для контент-менеджера, а не код, — но
шесть идей уже сделаны или противоречат зафиксированному 1:1 с эталоном.
Решение по каждому пункту, проверенное по коду:

| Тезис WPShop | Решение и проверка |
|---|---|
| Конструктор страниц из блоков (Tailor `structure` + repeater, `{% partial 'blocks/' ~ block.type %}`) | **Принято для новых страниц, пункт P2-24.** Сейчас страницы — файлы `themes/nlb/pages/*.htm` (26 шаблонов), Tailor хранит только контент (`type: stream` в `plugins/nlb/library/blueprints/*/item.yaml:5`). Перевести 110 существующих адресов на конструктор нельзя: их разметка и текст сверяются с `preview/` (`tools/check-dom-parity.mjs`) |
| TOC из `<h2>/<h3>` | **Принято как блок конструктора** (`P2-24`): PHP-парсер в плагине. На существующих страницах отклонено — оглавление добавляет текст и рвёт `check-dom-parity` |
| Прогресс-бар чтения, переключатель размера шрифта | **Отложено.** `themes/nlb/assets/js/script.js` побайтово равен источнику (73,6 КБ), эталона для новых элементов нет; решать вместе с тёмной темой, отдельным решением |
| Тёмная тема (`dark-theme` на `<body>`, CSS-переменные) | **Отложено, это решение владельца.** В `themes/nlb/assets/css/styles.css` тёмной темы нет; P2-15 уже фиксирует «тёмная тема — отдельное решение, не побочный эффект» |
| Управляемые баннеры/промо-блоки (позиция, страницы показа) | **Принято вторым шагом после P2-24** — отдельный blueprint `Nlb\Banner` + партиал. Сейчас промо-блоков нет, главная 1:1; новые позиции не трогают существующие |
| «Читайте также» (`getRelatedRecords()` + `Cache::remember` на 24 часа) | **Отложено до P2-23.** Кэш запроса сейчас живёт один запрос (`classes/Content.php:26`), а `Cache::remember` до полностраничного кэша отклонён (§4). Связность придётся строить по разделу: поля `tags` в blueprints нет |
| Расширение schema.org: FAQ для услуг, `Book` для книг | **Сделано/отклонено.** `Article`/`Event`/`Product`/`Service` и `BreadcrumbList` уже в `@graph` (`classes/Seo.php:399-520`, `:118`); `FAQPage` отклонён в Stage 16 (нет видимого блока «вопрос-ответ»); `Book` — фактическая ошибка черновика: раздел `books` — «Сувениры и подарки», `Product` верен |
| Поле `display_mode` в blueprint раздела | **Принято частично.** `blueprints/*/section.yaml` — это `structure` (дерево разделов), поле там никто не увидит; режим показа — настройка темы/страницы (P2-15) плюс отдельный партиал на пресет (`themes/nlb/partials/cards/`, 6 файлов) |
| Хлебные крошки отдельным Twig-партиалом с `BreadcrumbList` | **Уже сделано иначе (Stage 16).** `Seo::breadcrumbs()` (`classes/Seo.php:118`) строит цепочку из адреса в JSON-LD; видимых крошек эталон не содержит, партиал отклонён |
| Кнопка «Наверх» | **Отклонено для 110 адресов** — новый видимый элемент рвёт 1:1; допустимо только в новом шаблоне вместе с P2-24 |
| Шорткоды `[spoiler]`, `[button]`, `[current_year]` | **Отклонено в виде шорткодов.** В October нет их движка: richeditor отдаст текст как есть, а фильтр на выводе задел бы тексты всех 110 страниц. | «Обновите AGENTS.md правилами универсальных блоков» | **Отклонено как дубль:** роль играют §5–6 этого документа и раздел 5 `AGENTS.md`. Новое правило без предмета (конструктора) — третий источник, который протухнет |
