## 4. Отклонено

- **Fortify, CSP-плагин, Meilisearch, RainLab.Revisionable, Spatie Backup как
  плагины.** Правило «один плагин `nlb/library`» (`AGENTS.md`, правило 5,
  `docs/plugins.md`) не отменяется: то же делается кодом плагина или
  штатными таблицами. Исключение — только из списка `docs/plugins.md`.
- **Замена `Content::flush()` на тегированный кэш сейчас.** Кэш запроса не
  переживает запрос; теги появятся вместе с полностраничным кэшем, иначе это
  кэш ради кэша.
- **«Универсальные пути» вместо `D:\nlbbootstrap-main` в документации.**
  Источник миграции — часть условия задачи (`AGENTS.md`, §1), его путь должен
  быть точным. Машинные пути PHP/Composer остаются в `README.md` и
  `docs/installation.md` как инструкция для этой машины.
- **Snapshot-файл `.ai/context-snapshot.md` и `docs/ai-examples/`.** Их роль
  уже выполняют `Что сделано.txt` (что и чем проверено) и код проекта;
  третий журнал протухнет молча.

## 6. Шаблон и Tailor: пункты §9 оценки, которых не было в таблицах §2–3

Эти пять тезисов оценки 11.11.2026 не попали ни в «Принято», ни в
«Отклонено» — здесь решение по каждому, проверенное по коду:

| Тезис оценки | Решение и проверка |
|---|---|
| «Миксины Tailor для повторяющихся полей (`meta_title`, `meta_description`)» | **Принято, но вместе с ближайшей правкой blueprints.** `seo_title` и `seo_description` продублированы в шести файлах `plugins/nlb/library/blueprints/*/item.yaml` (по 6 вхождений каждого), а ядро умеет переиспользуемые наборы: `modules/tailor/classes/blueprint/MixinBlueprint.php:11`. `seo_image` и `seo_robots` — свойства страниц CMS, не Tailor (`themes/nlb/pages/personal.htm:3`), их mixin не касается. Делать на одной сущности и проверять `nlb:import` + `october:migrate`, иначе схема Tailor меняется вслепую. Строка добавлена в P2-19 |
| «Критический функционал работает без JS» | **Принято частично.** Формы — обычный `POST` и без JS работают, но мобильное меню (`themes/nlb/partials/header.htm:38`), выпадающие меню «Услуги»/«Печать» (`:48`, `:56`), модалки поиска (`:69`), реквизитов (`themes/nlb/pages/contacts.htm:44`) и обратной связи (`themes/nlb/partials/footer.htm:105`) держатся на `data-bs-toggle` и без JS не открываются. Полный `<noscript>`-дубль ломает 1:1 и `check-dom-parity`, поэтому проверка и минимальный фикс — в P1-5 |
| «Разбейте шаблон на атомарные паршалы (`button.htm`, `section-header.htm`)» | **Отклонено.** Карточки уже вынесены — `themes/nlb/partials/cards/` (6 файлов: `book`, `collection`, `event`, `news`, `print`, `service`); остальное — уникальная разметка конкретных страниц. Дробление ради дробления добавляет Twig-вызовы и мешает сверке 1:1 |
| `ml_`-префиксы для будущей мультиязычности | **Принято как заметка, не как работа.** Второй язык — P2-1; переименование полей сейчас сломало бы `nlb:import` и JSON-LD (`classes/Seo.php`), поэтому имена фиксируются в P2-1 и меняются одновременно с появлением второго языка |
| Zero-downtime деплой (`october:mirror` + атомарный symlink) и откат по тегам | **Принято, но после выбора хостинга.** `october:mirror` в 4.4 есть (`php artisan list`: «Generates a mirrored public folder using symbolic links»), на VPS атомарный symlink — часть деплоя; пока хостинг не выбран (M17), в P0-9 записан откат из бэкапа (P0-8) |

## 7. Как этим пользоваться

1. Перед новой работой — сверить пункт с этим документом: если он здесь
   «отклонено», второй раз не обсуждать.
2. Закрытый пункт бэклога удаляется из `Что доделать.txt` и попадает записью
   в `Что сделано.txt`; строку в таблице §2–3 тогда править не нужно —
   она ссылается на номер пункта, а номер исчезает вместе с пунктом.
3. Оценка не является источником факта: числа (тесты, адреса, размеры)
   берутся из прогона, а не из HTML.
